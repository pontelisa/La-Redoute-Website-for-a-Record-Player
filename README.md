# 3D Turntable Web Interface

This project was developed as part of a university course where the goal was to create a web interface in collaboration with La Redoute. The main task was to design and implement a custom turntable that users could explore and interact with.


## The site allows users to:

  - Explore the turntable in 3D

  - Interact with its components (needle, lid, rotation)

  - Customize materials and finishes


The project was completed in partnership with a colleague. The main objective was to provide a more immersive and interactive experience than traditional product pages, giving users a better understanding of the product before purchase.<br><br>
(We were also asked to create a prototype in Figma and perform a heuristic evaluation of the La Redoute website, but I'll not include here since the main focus was the 3D interface implementation).

## Note: 
The project and its documentation are written in Portuguese, as it was the language used in the course.
